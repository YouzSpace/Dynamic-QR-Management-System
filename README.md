# 微信活码管理系统

一个极致轻量的微信活码管理工具，无需数据库，上传即用。

## 功能特性

- **活码核心**：上传二维码图片，固定链接永远不变，顾客始终扫到最新码
- **可视化编辑器**：实时编辑标题、简介、底部提示文字，右侧即时预览
- **主题 & 模板**：5 种主题色 + 3 套页面模板，一键切换风格
- **自定义 HTML**：高级模式支持直接粘贴完整 HTML，完全自定义页面
- **历史回滚**：保留最近 10 次二维码更换记录，一键回滚到任意历史版本
- **PV 统计**：记录总访问量和今日访问量，后台仪表盘直观展示
- **敏感词检测**：保存时自动扫描微信敏感词并提醒
- **微信分享优化**：支持设置分享标题、描述和封面图

## 技术栈

- 后端：纯 PHP（无需数据库）
- 前端：HTML / CSS / JavaScript
- 数据存储：JSON 文件 + 文本日志
- 部署：任意支持 PHP 的服务器，无需额外配置

## 安装部署

1. 将项目上传至支持 PHP 的服务器
2. 确保以下目录/文件可写：
   - `data/` 目录
   - `uploads/` 目录
   - 根目录 `index.html`（发布时自动生成）
3. 访问 `your-domain.com/admin/` 进入后台
4. 默认密码：`admin123`（登录后请立即修改）

## 使用流程

1. **登录后台** → 修改默认密码
2. **上传二维码** → 在「二维码管理」中上传第一张二维码图片
3. **编辑页面内容** → 在「页面编辑器」中填写标题、简介等
4. **选择主题和模板** → 实时预览效果
5. **点击发布** → 生成顾客端访问页面
6. **分享链接** → 将首页链接分享给顾客，随时更换二维码无需重新生成

## 文件结构

```
├── admin/              # 后台管理系统
│   ├── index.php       # 后台入口页面
│   ├── config.php      # 核心配置 & 工具函数
│   ├── ajax.php        # AJAX 请求处理
│   ├── publish.php     # 静态页面发布
│   ├── css/style.css   # 后台样式
│   └── js/app.js      # 后台交互逻辑
├── templates/          # 前端页面模板
│   ├── template-1.php  # 简洁文字版
│   ├── template-2.php  # 卡片式
│   └── template-3.php  # 美食风格
├── data/               # 数据存储（需可写）
│   ├── settings.json   # 页面配置
│   ├── history.json    # 更换历史
│   └── logs.txt        # 操作日志
├── uploads/            # 上传文件目录（需可写）
│   └── wx-img.png     # 当前生效的二维码（固定文件名）
├── index.php           # 顾客访问入口（记录PV + 加载静态页）
├── preview.php         # 后台实时预览渲染器
└── index.html          # 发布生成的静态页面
```

## 注意事项

- 默认密码 `admin123` 请务必修改
- `data/` 和 `uploads/` 目录需要写权限
- 微信内分享封面图需单独上传（基础设置中操作）
- 敏感词仅为提醒，不会阻止保存
